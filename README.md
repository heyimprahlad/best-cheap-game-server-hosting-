## Before you buy: a 60-second checklist

- [ ] **RAM fits the game.** 1GB to 2GB covers vanilla Minecraft for a few friends. Modpacks want 4GB to 8GB. Palworld wants 8GB or more.
- [ ] **Price after month one.** Check whether the deal is first-month-only or recurring.
- [ ] **Prepay term.** A low monthly price on a 24-month term is a big upfront payment.
- [ ] **Refund window.** It ranges from none (unmanaged VPS) to 30 days.
- [ ] **Backups.** Confirm how many copies you get and whether extra ones cost money.
- [ ] **DDoS protection.** It should be included, not sold as an add-on.
- [ ] **Location.** Pick the data center closest to most of your players to keep ping low.
- [ ] **Mod support.** Look for CurseForge or Modrinth installers and Paper, Fabric or Forge server types if you plan to mod.

## Self-hosting on a cheap VPS

If you are comfortable on the Linux command line, a small VPS can beat managed hosting on RAM per dollar. A 2GB KVM VPS from [RackNerd](https://digitalprahlad.com/go/racknerd/) costs $35.99 a year and renews at the same price.

### Minecraft Java (vanilla)

```bash
sudo apt update && sudo apt install -y openjdk-21-jre-headless screen
mkdir ~/minecraft && cd ~/minecraft
# Download server.jar from the official page:
# https://www.minecraft.net/en-us/download/server
java -Xms1G -Xmx1536M -jar server.jar nogui
# Accept the EULA in eula.txt, then start it again
```

### Steam games with SteamCMD

```bash
# Install SteamCMD (see https://developer.valvesoftware.com/wiki/SteamCMD)
steamcmd +login anonymous +app_update <APP_ID> validate +quit
```

Replace `<APP_ID>` with the dedicated server app ID for your game, then open the game's port in your firewall.

### Want a web panel?

[Pterodactyl](https://pterodactyl.io/) is a free, open-source game server panel you can install on your own VPS to get one-click installs and a browser console, similar to what managed hosts give you.

**Trade-off:** you handle updates, backups and security yourself, and most budget VPS providers do not offer refunds.

**What is the cheapest game server you can rent?**

**Is 1GB of RAM enough?**
For vanilla Minecraft with two to four players, usually yes. For mods or more players, start at 4GB.

**Which host has the best refund?**
UltaHost and Hostinger both offer 30 days. Most others give 72 hours to 7 days.

**Are cheap game servers laggy?**
Not by default. Lag usually comes from too little RAM, a far-away location or too many plugins, not from the price.

BisectHosting and Nodecraft let you swap games on the same plan at no extra cost.
